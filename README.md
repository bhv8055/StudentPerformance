# 🎓 Student Performance Prediction System

An end-to-end Machine Learning project that predicts student mathematics performance using demographic and academic attributes. The project combines data analysis, feature engineering, regression models, and performance evaluation to identify the factors that influence student achievement.

---

## 🚀 Project Highlights

* 📊 Performed comprehensive Exploratory Data Analysis (EDA)
* 🧹 Cleaned and preprocessed raw student data
* 🔄 Applied feature encoding and transformation
* 🤖 Built multiple regression models
* 🌲 Implemented Random Forest and XGBoost Regressors
* ⚙️ Performed hyperparameter tuning using GridSearchCV
* 📈 Compared model performance using regression metrics
* 🔍 Analyzed feature importance and prediction errors

---

## 📂 Dataset

The dataset contains information about students, including:

* Gender
* Race/Ethnicity
* Parental Level of Education
* Lunch Type
* Test Preparation Course
* Reading Score
* Writing Score
* Mathematics Score (Target Variable)

---

## 📊 Key Insights

* Reading and writing scores are the strongest predictors of mathematics performance.
* Students who completed the test preparation course generally achieved higher scores.
* Parental education level positively influences student performance.
* Feature importance analysis helped identify the variables with the greatest impact on predictions.
